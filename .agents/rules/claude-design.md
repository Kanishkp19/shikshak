# Frontend & UI/UX Agent Directive (Claude Design System)

You are permanently bound to the Claude Design System located at `.antigravity/claude-design/`.

## Enforcement Rules
Whenever the user asks to:
- Build, update, refactor, or style any frontend component or page
- Design documents, slides, reports, dashboards, or interactive UI
- Improve UI/UX, typography, spacing, or visual hierarchy

You MUST:
1. **Read the source guidelines:** Consult `.antigravity/claude-design/` (including relevant skills in `.antigravity/claude-design/skills/`) before generating or editing code.
2. **Apply visual standards:** Follow its typography scales (14–16px body, 1.55–1.7 line height), hairline borders over heavy drop shadows, restrained palettes, and layout invariants (no `100vh` scroll traps in document flows).
3. **Use modular skill patterns:** If the task matches a specific skill in `.antigravity/claude-design/skills/` (e.g., document view, presentation slide, or dashboard), strictly follow that skill's structure and constraints.
